My Journey

I am a Software Quality professional with over 7.5 years of experiance in total and 5.5 years specializing in automation, I design reusable and maintainable framework architectures for enterprise environments. I contribute for Test case creation, Functional testing, UI automation, API automation, framework development, product testing and quality ownership.


My career evolved from manual and functional testing into automation engineering, API testing and modern end-to-end automation. I have worked extensively with Java, Selenium, Cucumber BDD, REST APIs and API automation, and currently work with Playwright and TypeScript for banking application automation.

QA Philosophy

Build confidence before release.
